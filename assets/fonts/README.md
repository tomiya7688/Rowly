# Noto Sans JP

Rowly GUI は、日本語を表示するために Google Fonts の Noto Sans JP を実行ファイルに同梱します。通常文字と等幅文字の両方で、既定フォントにない文字の代替として使います。

- 提供元: https://github.com/google/fonts/tree/main/ofl/notosansjp
- ファイル: `NotoSansJP[wght].ttf`（可変フォント。ここでは `NotoSansJP-variable.ttf` として保存）
- SHA-256: `C2F3B4D463500A2DDCD3849CDED1FCEEB9FD6D1C32E6CBECD568453BA50FC68F`
